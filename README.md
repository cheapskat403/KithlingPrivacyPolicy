# Kithling Privacy Policy and Support

Published for the App Store listing:

- Privacy policy: https://cheapskat403.github.io/KithlingPrivacyPolicy/
- Support: https://cheapskat403.github.io/KithlingPrivacyPolicy/support/

Both pages are generated by `AppStore/build-site.py` in the app's repository — the policy from `Kithling/PrivacyPolicy.md`, the same file the app shows under Settings → Privacy Policy, and support from `AppStore/Support.md`. Change them there and regenerate, so the site and the app never disagree.

Support requests arrive as issues here.
